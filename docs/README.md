# The curriculum

These Markdown files are the course. The site renders them at `/learn/<section>/<slug>`, so a file here is a page there.

| Folder | What it covers |
|---|---|
| `core-accounting/` | Rules that hold in every country: double entry, accruals, policies, the month-end close |
| `standards/` | IFRS/IAS, UK GAAP (FRS 102, 101, 105) and the Australian AASB standards |
| `australia/` | GST and BAS, PAYG and super, the Corporations Act, Xero/QBO AU setup |
| `uk/` | VAT and MTD, PAYE and CIS, the Companies Act 2006, Xero/QBO UK setup |

Rules for writing a doc are in `engineering/content-rules.md`. Every figure is written as `{{fact:key}}` and comes from `src/data/facts.json`.
